## 🚀 Project Overview

Financial institutions process millions of transactions daily, making fraud detection a critical challenge.

This project uses Machine Learning and Risk Analytics techniques to identify fraudulent credit card transactions while minimizing false positives.

### Business Goal
✔ Detect fraudulent transactions early

✔ Reduce financial losses

✔ Generate actionable risk insights

✔ Improve fraud investigation efficiency
